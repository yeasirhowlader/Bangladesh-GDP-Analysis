# Bangladesh GDP Analysis

## About the Project

This project analyzes the Gross Domestic Product (GDP) of Bangladesh using World Bank data.

## Data Source

World Bank — World Development Indicators

## Data Period

2010–2025

## Indicators

- GDP (Current US$)
- GDP in Billion US$
- Nominal GDP Change
- GDP Trend

## Tools Used

- Microsoft Excel
- GitHub
- World Bank Data

## Purpose

The purpose of this project is to understand the trend of Bangladesh's GDP and develop basic data analysis and visualization skills.
